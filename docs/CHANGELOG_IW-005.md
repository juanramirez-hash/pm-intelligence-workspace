# IW-005 — Inventory Workspace UI & Drill-down

## Added

- Inventory Workspace page at `/inventory`.
- KPI layer for inventory value, physical stock, inbound stock and priority risks.
- Filters by search, brand, location and action priority.
- Analytical segmentation by brand, location and product.
- Stock-status distribution panel.
- Risk and opportunity action panels.
- Position-level drill-down for the latest inventory snapshot.
