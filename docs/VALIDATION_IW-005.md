# Validation — IW-005

Run:

```text
npm run build
npm run lint
npm test
```

Functional validation:

1. Open `/inventory`.
2. Confirm the latest snapshot and KPIs are shown.
3. Change Brand, Location and Priority filters.
4. Switch between Brand, Location and Product dimensions.
5. Select an analytical row and confirm the position drill-down is filtered.
6. Confirm risks and opportunities react to the active filters.
7. Refresh the browser and confirm persisted inventory remains available.
